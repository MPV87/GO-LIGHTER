# GO®

Onepager für die Marke GO® (KP Plattner GmbH) – reine Marken- und Produktinfo, kein Shop.

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – Rechtliches
- `img/` – Produktfotos (freigestellt, WebP)
- `fonts/` – Quicksand und Open Sans, lokal eingebunden (OFL-Lizenz)
- `og-image.jpg` – Vorschaubild beim Teilen in Social Media / Messengern
